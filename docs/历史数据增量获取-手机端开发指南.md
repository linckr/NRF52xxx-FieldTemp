# 历史数据增量获取 - 手机端开发指南

## 1. 功能概述

历史数据增量获取功能允许手机端通过携带最后一条数据的时间戳，只获取时间戳大于该值的新数据，避免重复传输已有数据，提高传输效率。

### 1.1 核心优势

- **减少传输量**：只传输增量数据，大幅减少传输时间
- **降低功耗**：缩短传输时间，降低设备功耗
- **提高效率**：避免重复数据，提高整体系统效率
- **向后兼容**：写入 `0` 仍可获取全部数据

### 1.2 工作原理

```
手机端操作流程：
1. 获取本地最后一条数据的时间戳
2. 向历史数据特性写入时间戳（4字节，小端序）
3. 启用历史数据通知
4. 接收并解析增量数据
5. 检测结束标志（0xFF），完成获取
```

## 2. GATT 特性说明

### 2.1 历史数据特性

- **UUID**: `12340023-1234-5678-1234-56789abcdef0`
- **权限**: **Write + Notify**（可写 + 可通知）
- **服务 UUID**: `12340020-1234-5678-1234-56789abcdef0`

### 2.2 数据格式

#### 写入数据（手机端 → 设备端）

- **长度**: 4 字节
- **格式**: uint32_t，**小端序**（Little-Endian）
- **含义**: Unix 时间戳（秒）
- **特殊值**: `0` 表示发送全部历史数据

**示例**：
```javascript
// 时间戳 1704067200 的字节表示（小端序）
[0x00, 0xE6, 0x0F, 0x65]
```

#### 通知数据（设备端 → 手机端）

- **格式**: 与之前相同，每条记录 8 字节
  - 时间戳：4 字节（uint32_t，小端序）
  - 温度：2 字节（int16_t，单位 0.01°C，小端序）
  - 湿度：2 字节（uint16_t，单位 0.01%，小端序）
- **每个通知包**: 最多包含 2 条记录（16 字节）
- **结束标志**: 单字节包，值为 `0xFF`

#### 步骤 2: 获取历史数据（增量获取）

```java
// 全局变量
private boolean historyFetching = false;
private boolean historyComplete = false;
private List<HistoryRecord> historyData = new ArrayList<>();
private Handler historyTimeoutHandler = new Handler();
private Runnable historyTimeoutRunnable;

/**
 * 增量获取历史数据
 * @param lastTimestamp 本地最后一条数据的时间戳（0 表示获取全部）
 */
private void fetchHistoryIncremental(long lastTimestamp) {
    // 防止重复调用
    if (historyFetching) {
        Log.i("BLE", "历史数据正在获取中，请勿重复点击");
        return;
    }

    historyFetching = true;
    historyComplete = false;
    historyData.clear();

    try {
        // 1. 获取历史数据特性
        BluetoothGattService configService = gatt.getService(BleConstants.CONFIG_SERVICE_UUID);
        if (configService == null) {
            Log.e("BLE", "配置服务未找到");
            historyFetching = false;
            return;
        }

        BluetoothGattCharacteristic historyChar = 
            configService.getCharacteristic(BleConstants.HISTORY_CHAR_UUID);
        if (historyChar == null) {
            Log.e("BLE", "历史数据特性未找到");
            historyFetching = false;
            return;
        }

        // 2. 先停止之前的通知（如果已启动）
        gatt.setCharacteristicNotification(historyChar, false);
        Thread.sleep(200); // 等待状态清理

        // 3. 写入起始时间戳（4字节，小端序）
        if (lastTimestamp > 0) {
            ByteBuffer buffer = ByteBuffer.allocate(4);
            buffer.order(ByteOrder.LITTLE_ENDIAN);
            buffer.putInt((int) lastTimestamp);
            
            historyChar.setValue(buffer.array());
            historyChar.setWriteType(BluetoothGattCharacteristic.WRITE_TYPE_DEFAULT);
            
            boolean writeSuccess = gatt.writeCharacteristic(historyChar);
            if (!writeSuccess) {
                Log.e("BLE", "写入时间戳失败");
                historyFetching = false;
                return;
            }
            
            Log.i("BLE", "已写入起始时间戳: " + lastTimestamp);
            
            // 等待写入完成（在 onCharacteristicWrite 回调中确认）
            // 这里简化处理，直接继续
            Thread.sleep(100);
        } else {
            // 写入 0 表示获取全部数据
            ByteBuffer buffer = ByteBuffer.allocate(4);
            buffer.order(ByteOrder.LITTLE_ENDIAN);
            buffer.putInt(0);
            
            historyChar.setValue(buffer.array());
            gatt.writeCharacteristic(historyChar);
            Log.i("BLE", "已写入时间戳 0，将获取全部历史数据");
            Thread.sleep(100);
        }

        // 4. 启用通知
        gatt.setCharacteristicNotification(historyChar, true);
        BluetoothGattDescriptor descriptor = historyChar.getDescriptor(BleConstants.CCCD_DESCRIPTOR_UUID);
        if (descriptor != null) {
            descriptor.setValue(BluetoothGattDescriptor.ENABLE_NOTIFICATION_VALUE);
            gatt.writeDescriptor(descriptor);
        }

        // 5. 设置超时（60秒）
        historyTimeoutRunnable = () -> {
            if (!historyComplete) {
                Log.w("BLE", "历史数据获取超时，已接收 " + historyData.size() + " 条记录");
                historyFetching = false;
                gatt.setCharacteristicNotification(historyChar, false);
                updateHistoryUI();
            }
        };
        historyTimeoutHandler.postDelayed(historyTimeoutRunnable, 60000);

    } catch (Exception e) {
        Log.e("BLE", "获取历史数据失败: " + e.getMessage());
        historyFetching = false;
    }
}
```

#### 步骤 3: 接收数据回调

```java
@Override
public void onCharacteristicChanged(BluetoothGatt gatt, BluetoothGattCharacteristic characteristic) {
    if (characteristic.getUuid().equals(BleConstants.HISTORY_CHAR_UUID)) {
        byte[] data = characteristic.getValue();

        if (data == null || data.length == 0) {
            Log.w("BLE", "警告: 数据为空");
            return;
        }

        // 检查结束标志
        if (data.length == 1 && (data[0] & 0xFF) == 0xFF) {
            Log.i("BLE", "历史数据传输完成，共 " + historyData.size() + " 条记录");
            historyComplete = true;
            historyFetching = false;

            // 取消超时
            historyTimeoutHandler.removeCallbacks(historyTimeoutRunnable);

            // 停止通知
            BluetoothGattService configService = gatt.getService(BleConstants.CONFIG_SERVICE_UUID);
            if (configService != null) {
                BluetoothGattCharacteristic historyChar = 
                    configService.getCharacteristic(BleConstants.HISTORY_CHAR_UUID);
                if (historyChar != null) {
                    gatt.setCharacteristicNotification(historyChar, false);
                }
            }

            // 按时间戳排序并更新 UI
            Collections.sort(historyData, (a, b) -> Long.compare(a.timestamp, b.timestamp));
            updateHistoryUI();
            return;
        }

        // 解析数据包（每个包可能包含 1 或 2 条记录）
        ByteBuffer buffer = ByteBuffer.wrap(data).order(ByteOrder.LITTLE_ENDIAN);
        int recordsInPacket = 0;

        while (buffer.remaining() >= 8) {
            long timestamp = buffer.getInt() & 0xFFFFFFFFL; // 无符号转换
            short tempRaw = buffer.getShort();
            int humRaw = buffer.getShort() & 0xFFFF; // 无符号转换

            float temperature = tempRaw / 100.0f;
            float humidity = humRaw / 100.0f;

            historyData.add(new HistoryRecord(timestamp, temperature, humidity));
            recordsInPacket++;
        }

        if (recordsInPacket > 0) {
            Log.d("BLE", "解析到 " + recordsInPacket + " 条记录，总计 " + historyData.size() + " 条");
            // 实时更新显示（每20条更新一次，避免卡顿）
            if (historyData.size() % 20 == 0) {
                updateHistoryUI();
            }
        }
    }
}

@Override
public void onCharacteristicWrite(BluetoothGatt gatt, BluetoothGattCharacteristic characteristic, int status) {
    if (characteristic.getUuid().equals(BleConstants.HISTORY_CHAR_UUID)) {
        if (status == BluetoothGatt.GATT_SUCCESS) {
            Log.i("BLE", "时间戳写入成功");
        } else {
            Log.e("BLE", "时间戳写入失败，状态: " + status);
            historyFetching = false;
        }
    }
}
```

#### 步骤 4: 数据模型

```java
class HistoryRecord {
    long timestamp;    // Unix 时间戳（秒），0 表示未同步时间
    float temperature; // 温度（摄氏度）
    float humidity;    // 湿度（百分比）

    HistoryRecord(long timestamp, float temperature, float humidity) {
        this.timestamp = timestamp;
        this.temperature = temperature;
        this.humidity = humidity;
    }

    String getTimeString() {
        if (timestamp == 0) {
            return "未同步时间";
        }
        SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss", Locale.getDefault());
        return sdf.format(new Date(timestamp * 1000));
    }
}
```

#### 步骤 3: 获取历史数据（增量获取）

```swift
class BLEManager: NSObject, CBPeripheralDelegate {
    private var historyFetching = false
    private var historyComplete = false
    private var historyData: [HistoryRecord] = []
    private var historyTimeoutTimer: Timer?
    
    /**
     * 增量获取历史数据
     * @param lastTimestamp 本地最后一条数据的时间戳（0 表示获取全部）
     */
    func fetchHistoryIncremental(lastTimestamp: UInt32) {
        // 防止重复调用
        guard !historyFetching else {
            print("历史数据正在获取中，请勿重复点击")
            return
        }
        
        guard let peripheral = currentPeripheral,
              let configService = peripheral.services?.first(where: { $0.uuid == BleConstants.configServiceUUID }),
              let historyChar = configService.characteristics?.first(where: { $0.uuid == BleConstants.historyCharUUID }) else {
            print("历史数据特性未找到")
            return
        }
        
        historyFetching = true
        historyComplete = false
        historyData.removeAll()
        
        // 1. 先停止之前的通知
        peripheral.setNotifyValue(false, for: historyChar)
        Thread.sleep(forTimeInterval: 0.2)
        
        // 2. 写入起始时间戳（4字节，小端序）
        var timestamp = lastTimestamp.littleEndian
        let timestampData = Data(bytes: &timestamp, count: 4)
        
        peripheral.writeValue(timestampData, for: historyChar, type: .withResponse)
        
        if lastTimestamp > 0 {
            print("已写入起始时间戳: \(lastTimestamp)")
        } else {
            print("已写入时间戳 0，将获取全部历史数据")
        }
        
        // 等待写入完成（在 didWriteValueFor 回调中确认）
        Thread.sleep(forTimeInterval: 0.1)
        
        // 3. 启用通知
        peripheral.setNotifyValue(true, for: historyChar)
        
        // 4. 设置超时（60秒）
        historyTimeoutTimer = Timer.scheduledTimer(withTimeInterval: 60.0, repeats: false) { [weak self] _ in
            guard let self = self else { return }
            if !self.historyComplete {
                print("历史数据获取超时，已接收 \(self.historyData.count) 条记录")
                self.historyFetching = false
                peripheral.setNotifyValue(false, for: historyChar)
                self.updateHistoryUI()
            }
        }
    }
}
```

#### 步骤 4: 接收数据回调

```swift
func peripheral(_ peripheral: CBPeripheral, didUpdateValueFor characteristic: CBCharacteristic, error: Error?) {
    guard characteristic.uuid == BleConstants.historyCharUUID else { return }
    
    if let error = error {
        print("接收数据错误: \(error)")
        return
    }
    
    guard let data = characteristic.value, !data.isEmpty else {
        print("警告: 数据为空")
        return
    }
    
    // 检查结束标志
    if data.count == 1 && data[0] == BleConstants.endMarker {
        print("历史数据传输完成，共 \(historyData.count) 条记录")
        historyComplete = true
        historyFetching = false
        
        // 取消超时
        historyTimeoutTimer?.invalidate()
        historyTimeoutTimer = nil
        
        // 停止通知
        peripheral.setNotifyValue(false, for: characteristic)
        
        // 按时间戳排序并更新 UI
        historyData.sort { $0.timestamp < $1.timestamp }
        updateHistoryUI()
        return
    }
    
    // 解析数据包（每个包可能包含 1 或 2 条记录）
    var offset = 0
    while offset + 8 <= data.count {
        let timestamp = data.withUnsafeBytes { $0.load(fromByteOffset: offset, as: UInt32.self) }.littleEndian
        let tempRaw = data.withUnsafeBytes { $0.load(fromByteOffset: offset + 4, as: Int16.self) }.littleEndian
        let humRaw = data.withUnsafeBytes { $0.load(fromByteOffset: offset + 6, as: UInt16.self) }.littleEndian
        
        let temperature = Float(tempRaw) / 100.0
        let humidity = Float(humRaw) / 100.0
        
        historyData.append(HistoryRecord(
            timestamp: timestamp,
            temperature: temperature,
            humidity: humidity
        ))
        
        offset += 8
    }
    
    if offset > 0 {
        print("解析到 \(offset / 8) 条记录，总计 \(historyData.count) 条")
        // 实时更新显示（每20条更新一次）
        if historyData.count % 20 == 0 {
            updateHistoryUI()
        }
    }
}

func peripheral(_ peripheral: CBPeripheral, didWriteValueFor characteristic: CBCharacteristic, error: Error?) {
    if characteristic.uuid == BleConstants.historyCharUUID {
        if let error = error {
            print("时间戳写入失败: \(error)")
            historyFetching = false
        } else {
            print("时间戳写入成功")
        }
    }
}
```

```javascript
// utils/bleHistory.js

const CONFIG_SERVICE_UUID = '12340020-1234-5678-1234-56789abcdef0';
const HISTORY_CHAR_UUID = '12340023-1234-5678-1234-56789abcdef0';
const END_MARKER = 0xFF;

/**
 * 增量获取历史数据
 * @param {number} lastTimestamp - 本地最后一条数据的时间戳（0 表示获取全部）
 * @param {Function} onData - 数据接收回调
 * @param {Function} onComplete - 完成回调
 */
function fetchHistoryIncremental(lastTimestamp, onData, onComplete) {
  return new Promise((resolve, reject) => {
    let historyData = [];
    let historyFetching = false;
    let historyComplete = false;
    let timeoutTimer = null;

    // 防止重复调用
    if (historyFetching) {
      console.log('历史数据正在获取中，请勿重复点击');
      reject(new Error('正在获取中'));
      return;
    }

    historyFetching = true;
    historyComplete = false;
    historyData = [];

    // 1. 获取历史数据特性
    wx.getBLEDeviceServices({
      deviceId: deviceId,
      success: (res) => {
        const service = res.services.find(s => s.uuid === CONFIG_SERVICE_UUID);
        if (!service) {
          reject(new Error('配置服务未找到'));
          return;
        }

        wx.getBLEDeviceCharacteristics({
          deviceId: deviceId,
          serviceId: service.uuid,
          success: (res) => {
            const char = res.characteristics.find(c => c.uuid === HISTORY_CHAR_UUID);
            if (!char) {
              reject(new Error('历史数据特性未找到'));
              return;
            }

            // 2. 先停止之前的通知
            wx.notifyBLECharacteristicValueChange({
              deviceId: deviceId,
              serviceId: service.uuid,
              characteristicId: char.uuid,
              state: false,
              success: () => {
                // 等待状态清理
                setTimeout(() => {
                  // 3. 写入起始时间戳（4字节，小端序）
                  const buffer = new ArrayBuffer(4);
                  const view = new DataView(buffer);
                  view.setUint32(0, lastTimestamp, true); // true 表示小端序

                  wx.writeBLECharacteristicValue({
                    deviceId: deviceId,
                    serviceId: service.uuid,
                    characteristicId: char.uuid,
                    value: buffer,
                    success: () => {
                      console.log('已写入起始时间戳:', lastTimestamp);

                      // 4. 启用通知
                      wx.notifyBLECharacteristicValueChange({
                        deviceId: deviceId,
                        serviceId: service.uuid,
                        characteristicId: char.uuid,
                        state: true,
                        success: () => {
                          console.log('已启用历史数据通知');

                          // 5. 设置超时（60秒）
                          timeoutTimer = setTimeout(() => {
                            if (!historyComplete) {
                              console.warn('历史数据获取超时，已接收', historyData.length, '条记录');
                              historyFetching = false;
                              wx.notifyBLECharacteristicValueChange({
                                deviceId: deviceId,
                                serviceId: service.uuid,
                                characteristicId: char.uuid,
                                state: false
                              });
                              onComplete(historyData);
                            }
                          }, 60000);

                          // 6. 监听数据接收
                          wx.onBLECharacteristicValueChange((res) => {
                            if (res.characteristicId !== HISTORY_CHAR_UUID) return;

                            const data = new Uint8Array(res.value);
                            
                            // 检查结束标志
                            if (data.length === 1 && data[0] === END_MARKER) {
                              console.log('历史数据传输完成，共', historyData.length, '条记录');
                              historyComplete = true;
                              historyFetching = false;
                              
                              clearTimeout(timeoutTimer);
                              
                              wx.notifyBLECharacteristicValueChange({
                                deviceId: deviceId,
                                serviceId: service.uuid,
                                characteristicId: char.uuid,
                                state: false
                              });

                              // 按时间戳排序
                              historyData.sort((a, b) => a.timestamp - b.timestamp);
                              onComplete(historyData);
                              resolve(historyData);
                              return;
                            }

                            // 解析数据包
                            const buffer = new DataView(res.value.buffer);
                            let offset = 0;
                            
                            while (offset + 8 <= data.length) {
                              const timestamp = buffer.getUint32(offset, true);
                              const tempRaw = buffer.getInt16(offset + 4, true);
                              const humRaw = buffer.getUint16(offset + 6, true);
                              
                              const record = {
                                timestamp: timestamp,
                                temperature: tempRaw / 100.0,
                                humidity: humRaw / 100.0
                              };
                              
                              historyData.push(record);
                              onData(record);
                              offset += 8;
                            }
                          });
                        },
                        fail: (err) => {
                          console.error('启用通知失败:', err);
                          historyFetching = false;
                          reject(err);
                        }
                      });
                    },
                    fail: (err) => {
                      console.error('写入时间戳失败:', err);
                      historyFetching = false;
                      reject(err);
                    }
                  });
                }, 200);
              }
            });
          }
        });
      }
    });
  });
}
```

## 6. 注意事项

### 6.1 时间戳格式

- **必须使用小端序**（Little-Endian）编码
- 时间戳单位为**秒**（Unix 时间戳）
- 时间戳为 `0` 时，设备端会发送全部历史数据

### 6.2 操作顺序

**重要**：必须按照以下顺序操作：

1. **先停止通知**（如果之前已启用）
2. **写入时间戳**
3. **等待写入完成**（在写入回调中确认）
4. **启用通知**
5. **接收数据**

### 6.3 状态管理

- **防止重复调用**：使用标志位 `historyFetching` 防止重复请求
- **状态清理**：每次开始获取前，先停止之前的通知
- **超时处理**：建议设置 60 秒超时，防止长时间等待

### 6.4 数据排序

- 设备端按时间戳从旧到新的顺序发送
- 建议手机端接收完毕后再次按时间戳排序，确保数据顺序正确

### 6.5 边界情况

- **时间戳为 0**：发送全部历史数据
- **时间戳大于所有数据**：不发送任何数据（传输立即完成）
- **时间戳等于最新数据**：不发送任何数据（传输立即完成）

### 7.2 重试机制

```java
private static final int MAX_RETRIES = 3;
private int retryCount = 0;

private void fetchHistoryWithRetry(long lastTimestamp) {
    if (retryCount < MAX_RETRIES) {
        try {
            fetchHistoryIncremental(lastTimestamp);
        } catch (Exception e) {
            retryCount++;
            Log.w("BLE", "获取失败，重试 " + retryCount + "/" + MAX_RETRIES);
            handler.postDelayed(() -> fetchHistoryWithRetry(lastTimestamp), 1000);
        }
    } else {
        Log.e("BLE", "获取失败，已达最大重试次数");
        retryCount = 0;
    }
}
```
