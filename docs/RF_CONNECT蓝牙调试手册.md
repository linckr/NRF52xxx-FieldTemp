## 1. 应用介绍

### 1.1 关于 RF CONNECT

**RF CONNECT** 是 Nordic Semiconductor 官方提供的蓝牙低功耗（BLE）调试工具，支持 Android 和 iOS 平台。本手册介绍如何使用 RF CONNECT 调试 **E104-BT5010A 蓝牙温湿度采集设备**。

### 1.2 设备信息

- **设备名称**: `yodfz-temp`
- **设备类型**: BLE 外设（Peripheral）
- **芯片平台**: nRF52810
- **通讯协议**: BLE GATT (Generic Attribute Profile)

### 1.3 应用下载

- **Android**: 在 Google Play 搜索 "nRF Connect" 或访问 [Nordic 官网](https://www.nordicsemi.com/Software-and-tools/Development-Tools/nRF-Connect-for-mobile)
- **iOS**: 在 App Store 搜索 "nRF Connect"

## 2. 设备扫描与连接

### 2.1 启动扫描

1. 打开 **RF CONNECT** 应用
2. 点击右上角的 **"SCAN"** 按钮（或底部导航栏的扫描图标）
3. 应用开始扫描附近的 BLE 设备

### 2.2 查找目标设备

在扫描结果列表中查找设备名称 **`yodfz-temp`**：

- **设备名称**: `yodfz-temp`
- **信号强度**: RSSI 值（通常为 -30 到 -90 dBm）
- **MAC 地址**: 显示设备的蓝牙 MAC 地址

**提示**：
- 如果设备未出现在列表中，请确保设备已上电并处于广播状态
- 设备在未连接时会持续广播，连接后停止广播
- 如果设备距离较远，信号强度会较弱（RSSI 值更负）

### 2.3 连接设备

1. 点击设备列表中的 **`yodfz-temp`** 设备
2. 应用会自动连接设备
3. 连接成功后，界面会显示设备的 **GATT 服务列表**

**连接状态指示**：
- **未连接**: LINK LED（P0.30）闪烁
- **已连接**: LINK LED（P0.30）常亮

## 3. 时间同步服务

### 3.1 服务信息

| 项目 | UUID | 说明 |
|------|------|------|
| **服务 UUID** | `12340010-1234-5678-1234-56789ABCDEF0` | 时间同步服务 |
| **时间特性 UUID** | `12340011-1234-5678-1234-56789ABCDEF0` | 可写，接收时间戳 |

### 3.2 操作步骤

#### 步骤 1: 找到时间同步服务

1. 连接设备后，在服务列表中找到 UUID 为 `12340010-1234-5678-1234-56789ABCDEF0` 的服务
2. 点击展开该服务，查看其特性列表

#### 步骤 2: 找到时间特性

在服务下找到 UUID 为 `12340011-1234-5678-1234-56789ABCDEF0` 的特性（Characteristic）

#### 步骤 3: 写入时间戳

1. 点击时间特性，进入特性详情页面
2. 点击 **"WRITE"** 或 **"↑"** 按钮
3. 在数据输入框中输入时间戳数据

**数据格式**：
- **格式**: 4 字节，小端序（Little Endian）
- **单位**: Unix 时间戳（秒，从 1970-01-01 00:00:00 UTC 起）
- **示例**: 当前时间 2024-01-01 00:00:00 UTC 对应时间戳 `1704067200`（十进制）

**输入方式**：
- **方式 1（十六进制）**: 输入 `00 C8 A8 65`（小端序，对应时间戳 1704067200）
- **方式 2（十进制）**: 部分应用支持直接输入十进制时间戳

**时间戳计算工具**：
- 在线工具: https://www.epochconverter.com/
- 命令行（Linux/Mac）: `date +%s`
- PowerShell（Windows）: `[int][double]::Parse((Get-Date -UFormat %s))`

#### 步骤 4: 确认写入

1. 确认数据格式正确后，点击 **"SEND"** 或 **"WRITE"** 按钮
2. 如果写入成功，设备会：
   - 在串口输出时间同步成功信息
   - DATA LED（P0.31）闪烁 3 次，表示时间同步成功

### 3.3 验证时间同步

**方法 1**: 查看设备串口输出
- 连接串口调试工具（115200 波特率）
- 查看是否有 `[时间同步] 成功！时间戳: xxx` 的输出

**方法 2**: 读取设备状态
- 通过配置服务的状态特性查看时间同步状态（见第 4 节）

## 4. 配置服务

### 4.1 服务信息

| 项目 | UUID | 说明 |
|------|------|------|
| **服务 UUID** | `12340020-1234-5678-1234-56789ABCDEF0` | 配置服务 |
| **采集间隔特性 UUID** | `12340021-1234-5678-1234-56789ABCDEF0` | 可读/可写 |
| **当前状态特性 UUID** | `12340022-1234-5678-1234-56789ABCDEF0` | 可读/可通知 |

### 4.2 采集间隔特性操作

#### 读取采集间隔

1. 在配置服务下找到 UUID 为 `12340021-1234-5678-1234-56789ABCDEF0` 的特性
2. 点击特性，进入详情页面
3. 点击 **"READ"** 或 **"↓"** 按钮
4. 应用会显示当前采集间隔值

**数据格式**：
- **格式**: 2 字节，小端序（Little Endian）
- **单位**: 秒
- **范围**: 10 ~ 3600 秒
- **默认值**: 30 秒

**示例**：
- 读取值 `1E 00`（十六进制） = 30（十进制）秒
- 读取值 `3C 00`（十六进制） = 60（十进制）秒

#### 设置采集间隔

1. 点击采集间隔特性，进入详情页面
2. 点击 **"WRITE"** 或 **"↑"** 按钮
3. 在数据输入框中输入新的采集间隔值

**输入格式**：
- **方式 1（十六进制）**: 输入 `3C 00`（表示 60 秒，小端序）
- **方式 2（十进制转十六进制）**: 
  - 30 秒 → `1E 00`
  - 60 秒 → `3C 00`
  - 300 秒（5分钟）→ `2C 01`
  - 3600 秒（1小时）→ `10 0E`

**注意事项**：
- 必须使用小端序（低字节在前）
- 值必须在 10 ~ 3600 秒范围内
- 写入成功后，设备会立即应用新配置并保存到 Flash

### 4.3 当前状态特性操作

#### 读取当前状态

1. 在配置服务下找到 UUID 为 `12340022-1234-5678-1234-56789ABCDEF0` 的特性
2. 点击特性，进入详情页面
3. 点击 **"READ"** 或 **"↓"** 按钮
4. 应用会显示当前状态数据

**数据格式**（6 字节）：
- **字节 0-1**: 采集间隔（uint16_t，小端序，单位：秒）
- **字节 2-3**: 记录数（uint16_t，小端序）
- **字节 4**: 系统状态（bit0=连接状态，bit1=时间同步状态）
  - `0x01`: 已连接
  - `0x02`: 时间已同步
  - `0x03`: 已连接且时间已同步
- **字节 5**: 保留（通常为 `0x00`）

**示例解析**：
```
数据: 1E 00 64 00 03 00
解析:
- 采集间隔: 1E 00 = 30 秒
- 记录数: 64 00 = 100
- 系统状态: 03 = 0b00000011 = 已连接(bit0) + 时间已同步(bit1)
- 保留: 00
```

#### 订阅状态通知

1. 点击状态特性，进入详情页面
2. 找到 **CCC (Client Characteristic Configuration)** 描述符
   - UUID: `00002902-0000-1000-8000-00805f9b34fb`
3. 点击 CCC 描述符，进入详情页面
4. 点击 **"WRITE"** 按钮
5. 输入 `01 00`（启用通知）或 `00 00`（禁用通知）
6. 点击 **"SEND"** 确认

**启用通知后**：
- 设备状态发生变化时（如采集间隔更新、记录数增加），会自动推送通知
- 应用会实时显示最新的状态数据

## 5. 温湿度服务

### 5.1 服务信息

| 项目 | UUID | 说明 |
|------|------|------|
| **服务 UUID** | `12340001-1234-5678-1234-56789ABCDEF0` | 温湿度服务 |
| **温度特性 UUID** | `12340002-1234-5678-1234-56789ABCDEF0` | 可读/可通知 |
| **湿度特性 UUID** | `12340003-1234-5678-1234-56789ABCDEF0` | 可读/可通知 |

### 5.2 温度特性操作

#### 读取温度值

1. 在温湿度服务下找到 UUID 为 `12340002-1234-5678-1234-56789ABCDEF0` 的特性
2. 点击特性，进入详情页面
3. 点击 **"READ"** 或 **"↓"** 按钮
4. 应用会显示当前温度值

**数据格式**：
- **格式**: 2 字节，小端序（Little Endian）
- **类型**: int16_t（有符号整数）
- **单位**: 0.01°C（实际值 = 读取值 / 100）
- **范围**: -4000 ~ 8500（对应 -40.00°C ~ 85.00°C）

**示例解析**：
```
读取值: 93 09 (十六进制)
转换为十进制: 0x0993 = 2451
实际温度: 2451 / 100 = 24.51°C
```

#### 订阅温度通知

1. 点击温度特性，进入详情页面
2. 找到 **CCC 描述符**（UUID: `00002902-0000-1000-8000-00805f9b34fb`）
3. 点击 CCC 描述符，写入 `01 00` 启用通知
4. 启用后，设备会按照采集间隔自动推送温度数据

**通知频率**：
- 默认每 30 秒推送一次（可在配置服务中修改采集间隔）
- 每次推送时，DATA LED（P0.31）会短暂闪烁

### 5.3 湿度特性操作

#### 读取湿度值

1. 在温湿度服务下找到 UUID 为 `12340003-1234-5678-1234-56789ABCDEF0` 的特性
2. 点击特性，进入详情页面
3. 点击 **"READ"** 或 **"↓"** 按钮
4. 应用会显示当前湿度值

**数据格式**：
- **格式**: 2 字节，小端序（Little Endian）
- **类型**: uint16_t（无符号整数）
- **单位**: 0.01%（实际值 = 读取值 / 100）
- **范围**: 0 ~ 10000（对应 0.00% ~ 100.00%）

**示例解析**：
```
读取值: 94 19 (十六进制)
转换为十进制: 0x1994 = 6548
实际湿度: 6548 / 100 = 65.48%
```

#### 订阅湿度通知

1. 点击湿度特性，进入详情页面
2. 找到 **CCC 描述符**，写入 `01 00` 启用通知
3. 启用后，设备会按照采集间隔自动推送湿度数据

## 6. 数据格式说明

### 6.1 字节序说明

**所有数据均使用小端序（Little Endian）**，即低字节在前，高字节在后。

**示例**：
- 十进制 30 → 十六进制 `0x001E` → 小端序字节序列 `1E 00`
- 十进制 60 → 十六进制 `0x003C` → 小端序字节序列 `3C 00`
- 十进制 1704067200 → 十六进制 `0x65A8C800` → 小端序字节序列 `00 C8 A8 65`

### 6.2 数据格式汇总表

| 特性 | 数据类型 | 字节数 | 单位 | 范围 | 示例 |
|------|----------|--------|------|------|------|
| 时间戳 | uint32_t | 4 | 秒 | 0 ~ 4294967295 | `00 C8 A8 65` = 1704067200 |
| 采集间隔 | uint16_t | 2 | 秒 | 10 ~ 3600 | `1E 00` = 30 |
| 记录数 | uint16_t | 2 | 条 | 0 ~ 65535 | `64 00` = 100 |
| 温度 | int16_t | 2 | 0.01°C | -4000 ~ 8500 | `93 09` = 24.51°C |
| 湿度 | uint16_t | 2 | 0.01% | 0 ~ 10000 | `94 19` = 65.48% |

### 6.3 数据转换工具

**在线工具**：
- Unix 时间戳转换: https://www.epochconverter.com/
- 十六进制转换: https://www.rapidtables.com/convert/number/hex-to-decimal.html

**命令行工具**：
```bash
# 获取当前 Unix 时间戳（Linux/Mac）
date +%s

# 获取当前 Unix 时间戳（Windows PowerShell）
[int][double]::Parse((Get-Date -UFormat %s))

# 十六进制转十进制（Python）
python3 -c "print(0x1E00)"

# 十进制转十六进制（Python）
python3 -c "print(hex(30))"
```

## 7. 常见问题排查

### 7.1 扫描不到设备

**可能原因**：
1. 设备未上电或未启动
2. 设备距离过远
3. 手机蓝牙未开启
4. 应用权限不足（Android 6.0+ 需要位置权限）

**解决方法**：
1. 检查设备电源和串口输出，确认设备正常运行
2. 靠近设备（建议 1 米内）
3. 检查手机蓝牙设置，确保蓝牙已开启
4. 在手机设置中授予应用位置权限（Android）

### 7.2 连接失败

**可能原因**：
1. 设备已被其他设备连接（BLE 外设通常只支持一个连接）
2. 设备处于低功耗模式，广播间隔较长
3. 手机蓝牙栈问题

**解决方法**：
1. 断开其他设备的连接
2. 等待设备重新开始广播（可能需要几秒）
3. 重启手机蓝牙或重启应用

### 7.3 读取/写入失败

**可能原因**：
1. 数据格式错误（字节序、长度等）
2. 值超出允许范围
3. 特性权限不足

**解决方法**：
1. 检查数据格式，确保使用小端序
2. 验证值是否在允许范围内（如采集间隔 10~3600 秒）
3. 确认特性支持该操作（Read/Write）

### 7.4 通知不工作

**可能原因**：
1. CCC 描述符未正确配置
2. 通知未启用

**解决方法**：
1. 检查 CCC 描述符是否写入 `01 00`（启用通知）
2. 重新连接设备并重新配置通知

### 7.5 数据值异常

**可能原因**：
1. 字节序错误（使用了大端序）
2. 数据类型理解错误（有符号/无符号）

**解决方法**：
1. 确认使用小端序（低字节在前）
2. 温度使用有符号整数（int16_t），湿度使用无符号整数（uint16_t）

## 9. 快速参考

### 9.1 常用操作流程

**首次连接并配置设备**：
1. 扫描并连接 `yodfz-temp` 设备
2. 同步时间（写入时间戳到时间特性）
3. 读取当前采集间隔
4. 根据需要修改采集间隔
5. 订阅温湿度通知
6. 订阅状态通知

**日常监控**：
1. 连接设备
2. 订阅温湿度通知（自动接收数据）
3. 查看实时温湿度值

### 9.2 数据格式速查

| 操作 | 输入格式 | 示例 |
|------|----------|------|
| 设置采集间隔 60 秒 | 2 字节，小端序 | `3C 00` |
| 设置采集间隔 300 秒 | 2 字节，小端序 | `2C 01` |
| 同步时间（2024-01-01 00:00:00） | 4 字节，小端序 | `00 C8 A8 65` |
| 启用通知 | 2 字节 | `01 00` |
| 禁用通知 | 2 字节 | `00 00` |
