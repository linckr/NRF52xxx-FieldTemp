nRF Connect SDK（NCS/Zephyr）配置
在prj.conf中添加：
# 启用DCDC转换器
CONFIG_NRF_POWER_DCDC_ENABLE=y
# 射频电路强制使用DCDC
CONFIG_BT_CTLR_DCDC_ENABLE=y
# 系统电源管理优化
CONFIG_PM=y
代码中验证：

#include <zephyr/drivers/clock_control.h>
#include <zephyr/drivers/power.h>

if (power_dcdc_is_enabled()) {
    printk("DCDC is enabled\n");
}
