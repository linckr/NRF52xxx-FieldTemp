蓝牙温湿度采集系统
******************

基于 Zephyr RTOS 和 Nordic nRF52810 的蓝牙低功耗温湿度采集设备，使用 E104-BT5010A 模块。

项目概述
********

本项目实现了一个低功耗的蓝牙温湿度监测设备，主要功能包括：

- **温湿度采集**：使用 AHT30 传感器采集环境温湿度数据
- **蓝牙传输**：通过 BLE GATT 服务实时传输温湿度数据
- **数据存储**：将采集的数据存储在 Flash 中，支持历史数据查询
- **时间同步**：通过蓝牙接收手机时间进行系统时间同步
- **低功耗运行**：支持可配置的采集间隔和系统级电源管理
- **状态指示**：使用 LED 灯指示系统运行状态和蓝牙连接状态

硬件要求
********

- **开发板**：E104-BT5010A（基于 nRF52810）
- **温湿度传感器**：AHT30（I2C 接口）
- **LED 指示灯**：
  - DATA LED：P0.31（数据状态指示）
  - LINK LED：P0.30（蓝牙连接状态指示）
  - 注意：P0.31和P0.30是低电平有效，高电平熄灭

硬件连接
========

- **I2C 传感器接口**：
  - SDA：P0.7
  - SCL：P0.6
- **UART 调试接口**：
  - TX：P0.18
  - RX：P0.14
  - 波特率：115200

重要配置说明
============

**时钟配置**：
  E104-BT5010A 模块没有外部晶振，必须使用内部 RC 振荡器。
  已在 ``prj.conf`` 中配置 ``CONFIG_CLOCK_CONTROL_NRF_K32SRC_RC=y``，
  确保系统不会因等待外部晶振起振而卡死。

**LED 配置**：
  - LED 为低电平有效（低电平点亮，高电平熄灭）
  - DATA LED 用于指示数据采集和传输状态
  - LINK LED 用于指示蓝牙连接状态

编译和烧录
**********

环境要求
========

- **NCS 版本**：3.2.1
- **工具链**：Nordic nRF Connect SDK

编译步骤
========

**E104-BT5010A (nRF52810)** 在项目根目录下执行：

.. code-block:: bash

   west build -b e104_bt5010a_tb --build-dir build

**nRF52832 开发板** 编译固件到 52832 板子：

.. code-block:: bash

   west build -b nrf52832dk_nrf52832 --build-dir build_nrf52832

板级 overlay 使用 ``boards/nrf52832dk_nrf52832_cpuapp.overlay``，引脚与 E104-BT5010A 一致
（UART 18/14、I2C 6/7、SPI 30/31/29、W25Q64 CS 28）。烧录 52832 固件：

.. code-block:: bash

   west flash -d build_nrf52832

如果需要清理之前的构建：

.. code-block:: bash

   west build -t clean

烧录程序
========

使用 J-Link 或其他支持的烧录工具：

.. code-block:: bash

   west flash

如果使用 nrfjprog：

.. code-block:: bash

   nrfjprog --program build/zephyr/zephyr.hex --chiperase --verify --reset

主要功能
********

温湿度采集
==========

- 使用 AHT30 传感器通过 I2C 接口采集温湿度
- 支持可配置的采集间隔（通过蓝牙服务配置）
- 采集的数据会自动存储到 Flash

蓝牙服务
========

设备提供以下 BLE GATT 服务：

**温湿度服务** (UUID: 12340001-1234-5678-1234-56789ABCDEF0)
  - 温度特性：读取当前温度值（可读/可通知）
    UUID: 12340002-1234-5678-1234-56789ABCDEF0
    数据格式：int16_t，单位：0.01°C（例如：2350 = 23.50°C）
  - 湿度特性：读取当前湿度值（可读/可通知）
    UUID: 12340003-1234-5678-1234-56789ABCDEF0
    数据格式：uint16_t，单位：0.01%（例如：6500 = 65.00%）
  - 支持自动通知：客户端订阅后，设备会在每次采集到新数据时自动推送

**时间同步服务** (UUID: 12340010-1234-5678-1234-56789ABCDEF0)
  - 时间特性：接收手机时间进行系统时间同步
  - UUID: 12340011-1234-5678-1234-56789ABCDEF0

**配置服务** (UUID: 12340020-1234-5678-1234-56789ABCDEF0)
  - 采集间隔特性：设置温湿度采集间隔（单位：秒）
    UUID: 12340021-1234-5678-1234-56789ABCDEF0
  - 状态特性：查询当前设备状态（采集间隔、存储空间等）
    UUID: 12340022-1234-5678-1234-56789ABCDEF0

数据存储
========

- 设备配置（采集间隔等）存储在 Flash 中
- 温湿度数据通过蓝牙实时传输，当前版本暂未实现本地历史数据存储

低功耗管理
==========

- 支持系统级电源管理
- 在采集间隔期间进入低功耗模式
- 蓝牙连接时保持活动状态以响应请求

状态指示
========

- **初始化阶段**：两个 LED 同时闪烁（间隔 200ms）
- **蓝牙就绪但未连接**：LINK LED 闪烁（间隔 500ms），表示等待连接
- **蓝牙连接后**：LINK LED 常亮，表示已连接
- **时间同步时**：DATA LED 快速闪烁3次（间隔 100ms）
- **温湿度数据更新时**：DATA LED 短暂点亮 50ms（仅在蓝牙连接时）

故障排查
********

常见问题：

1. **编译错误：找不到 led0 别名**
   - 说明：此项目不使用标准的 ``led0`` 别名，而是直接使用 GPIO 引脚控制
   - 解决：无需修改，代码中直接使用 ``P0.31`` 和 ``P0.30``

2. **系统启动后卡死**
   - 检查时钟配置是否正确（必须使用内部 RC）
   - 检查 UART 配置是否正确（不应启用硬件流控）

3. **内存不足**
   - nRF52810 内存较小，已优化配置减少内存占用
   - 如果添加新功能，注意内存使用情况

4. **蓝牙连接失败**
   - 检查设备名称配置（默认："yodfz-temp"）
   - 本设备使用 "Just Works" 无配对连接
