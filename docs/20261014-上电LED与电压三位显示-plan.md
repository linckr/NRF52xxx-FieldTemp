# 上电提示与电压三位显示

## 需求与实现

CR2032电池座接触不良时，需要可观察的启动提示。复用现有LED GPIO模块，在应用main最早的led_init后、NVS和蓝牙启动前，让LINK灯250 ms亮/250 ms灭，共6次、3秒。之后恢复原有未连接熄灯、连接LINK常亮行为。不新增线程或定时器；删除原停用初始化work。软件重启也会提示；MCUboot失败于应用之前时仍无提示，本次不改MCUboot。

App全部电压展示由1/2位统一3位小数，覆盖首页、历史列表/详情、配置、设备管理、电池指示器和日志。不改变毫伏存储、BLE协议或ADC精度。
