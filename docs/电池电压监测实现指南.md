# E104-BT5010A 电池电压监测实现指南

## 项目说明：已移除电压计算 / 不使用 VDD 测量

**本项目中已移除所有 VDD 电压测量与电压计算相关代码。**

- **nRF52810 不支持内部 VDD 通道**：使用 HAL 或 Zephyr API 测量 VDD 时，采样值为 0 或返回错误（如 -5、-22），属芯片限制，非代码问题。
- 若需电池电压监测，请使用 **方案 C**（外部分压电路 + ADC 引脚）。方案 B（内部 VDD 测量）在 nRF52810 上不可用。

## 如何确认模块是否有电池监测引脚

### 方法 1：查看数据手册引脚定义表

打开 `E104-BT5010A+datasheet_CN_v2.0.pdf` 数据手册，查找以下内容：

1. **引脚定义表（Pin Definition）**

   - 查找是否有标注为 **"VBAT"**、**"BAT"**、**"BATTERY"** 或 **"AINx"** 的引脚
   - 查看是否有分压电阻相关的说明（如 "1/3 Divider" 等）

2. **原理图部分**

   - 查找电池供电部分的电路图
   - 确认是否有分压电路连接到 ADC 引脚

3. **典型应用电路**
   - 查看是否有电池监测的应用示例

### 方法 2：查看 nRF52810 芯片的 ADC 引脚

nRF52810 芯片支持 SAADC（Successive Approximation ADC），可用的模拟输入通道：

| ADC 通道 | nRF52810 引脚 | 说明                                           |
| -------- | ------------- | ---------------------------------------------- |
| AIN0     | P0.02         | 模拟输入通道 0                                 |
| AIN1     | P0.03         | 模拟输入通道 1                                 |
| AIN2     | P0.04         | 模拟输入通道 2                                 |
| AIN3     | P0.05         | 模拟输入通道 3                                 |
| AIN4     | P0.28         | 模拟输入通道 4                                 |
| AIN5     | P0.29         | 模拟输入通道 5                                 |
| AIN6     | P0.30         | 模拟输入通道 6（**注意：已被 LINK LED 占用**） |
| AIN7     | P0.31         | 模拟输入通道 7（**注意：已被 DATA LED 占用**） |
| VDD      | -             | **可直接测量芯片供电电压（VDD）**              |

**重要提示**：

- 当前项目已使用 P0.30（LINK LED）和 P0.31（DATA LED）
- 如果模块没有专门的电池监测引脚，可以使用 **VDD 测量**（测量芯片供电电压，间接反映电池电压）
- 如果电池电压超过 ADC 量程（通常 0-3.6V），需要使用分压电路

### 方法 3：测量方式验证

#### 3.1 使用万用表测量

1. **找到 VCC 引脚**：在模块上找到供电引脚（通常标注为 VCC 或 VBAT）
2. **找到 ADC 引脚**：测量空闲的 ADC 引脚（如 P0.02、P0.03、P0.04、P0.05）是否有电压
3. **如果有电压且与电池电压成比例**：说明内部有分压电路

#### 3.2 使用示波器/逻辑分析仪

- 检查 ADC 引脚的电压波形
- 判断是否有分压电路连接

检查项目中是否已有 ADC 配置：

## 实现方案

### 方案 A：如果模块有专门的电池监测引脚

1. 在 `app.overlay` 中配置 ADC 通道
2. 使用 Zephyr ADC API 读取电压
3. 转换为容量百分比

### 方案 B：使用 VDD 测量（**nRF52810 上不可用，已废弃**）

nRF52810 **不支持**内部 VDD 测量，使用 `NRF_SAADC_INPUT_VDD` 时采样值始终为 0，Zephyr ADC 通道配置会失败（如 -22）。**本项目已移除电压计算，请勿在代码中加入 VDD 测量。**

### 方案 C：使用外部分压电路（推荐实现方案）

**已验证：nRF52810 不支持 `NRF_SAADC_INPUT_VDD` 功能，必须使用外部 ADC 引脚配合分压电路。**

#### 硬件连接

```
电池正极 (VBAT, 3.0-4.2V)
    |
    [R1: 480kΩ]  ← 上电阻
    |
    +----> P0.02 (ADC 输入，AIN0)
    |
    [R2: 480kΩ]  ← 下电阻
    |
电池负极 (GND)
```

#### 电阻选择

**推荐方案：两个 480kΩ 电阻（1:1 分压）**

- **R1 = 480kΩ**（上电阻，连接电池正极）
- **R2 = 480kΩ**（下电阻，连接 GND）
- **分压比 = 0.5**（1/2）
- **ADC 输入范围**：
  - 电池 3.7V 时：ADC = 1.85V（安全）
  - 电池 4.2V 时：ADC = 2.1V（安全）

**优点**：

- 计算简单：实际电压 = ADC 电压 × 2
- 电阻相同，采购方便
- 功耗低：约 3.85µA（3.7V 时）
- 在 ADC 量程内，安全可靠

**其他可选方案**：

| R1   | R2   | 分压比 | 4.2V 时 ADC | 功耗   | 说明               |
| ---- | ---- | ------ | ----------- | ------ | ------------------ |
| 480k | 480k | 0.5    | 2.1V        | 3.85µA | **推荐**，计算简单 |
| 470k | 330k | 0.413  | 1.73V       | 4.6µA  | 原推荐方案         |
| 1M   | 1M   | 0.5    | 2.1V        | 1.85µA | 更低功耗           |

#### 功耗分析

使用 480kΩ × 2 分压电路：

```
总电阻 = 960kΩ
电流 = VBAT / 960kΩ

当电池电压为 3.7V 时：
电流 = 3.7V / 960kΩ = 3.85µA

当电池电压为 4.2V 时：
电流 = 4.2V / 960kΩ = 4.38µA
```

**功耗评估**：

- 持续消耗：分压电路会一直消耗电流
- 影响：对于 100mAh 电池，理论续航约 3 年（仅分压电路）
- 相比系统其他功耗（蓝牙、传感器等），影响很小

**如需进一步降低功耗**：

- 使用更高阻值（1MΩ × 2），功耗约 1.85µA
- 使用 MOSFET 开关控制（需要测量时才开启）

**2. 设备树配置（`app.overlay`）**

```dts
&adc {
	status = "okay";
	/delete-property/ zephyr,pm-device-runtime-auto;

	#address-cells = <1>;
	#size-cells = <0>;

	channel@0 {
		reg = <0>;
		zephyr,gain = "ADC_GAIN_1_6";
		zephyr,reference = "ADC_REF_INTERNAL";
		zephyr,acquisition-time = <ADC_ACQ_TIME_DEFAULT>;
		zephyr,input-positive = <NRF_SAADC_AIN0>;  /* P0.02 */
		zephyr,resolution = <14>;
	};
};
```

**3. 代码实现（`src/main.c`）**

**方法 A：使用 Nordic HAL 直接操作（推荐，更简单）**

```c
#include <hal/nrf_saadc.h>

// 分压电路参数（480kΩ × 2，分压比 0.5）
#define VOLTAGE_DIVIDER_RATIO 2  // 实际电压 = ADC电压 × 2

/**
 * @brief 读取电池电压（通过外部ADC引脚P0.02配合分压电路）
 * @param voltage_mv 输出参数，电压值（单位：毫伏）
 * @return 0 成功，负数表示错误
 */
static int battery_voltage_read(uint16_t *voltage_mv)
{
	if (voltage_mv == NULL) {
		return -EINVAL;
	}

	// 临时禁用 SAADC（如果已启用）
	bool saadc_enabled = nrf_saadc_enable_check(NRF_SAADC);
	if (saadc_enabled) {
		nrf_saadc_disable(NRF_SAADC);
		k_msleep(1);
	}

	// 配置 SAADC 通道 0 用于外部 ADC 输入（P0.02/AIN0）
	nrf_saadc_channel_config_t channel_config;
	channel_config.resistor_p = NRF_SAADC_RESISTOR_DISABLED;  // 上拉电阻禁用
	channel_config.resistor_n = NRF_SAADC_RESISTOR_DISABLED;  // 下拉电阻禁用
	channel_config.gain = NRF_SAADC_GAIN1_6;  // 增益 1/6
	channel_config.reference = NRF_SAADC_REFERENCE_INTERNAL;  // 内部参考电压 0.6V
	channel_config.acq_time = NRF_SAADC_ACQTIME_10US;  // 采集时间 10us
	channel_config.mode = NRF_SAADC_MODE_SINGLE_ENDED;  // 单端模式
	channel_config.burst = NRF_SAADC_BURST_DISABLED;  // 禁用突发模式

	// 使用外部 ADC 引脚 P0.02（AIN0）
	nrf_saadc_channel_input_set(NRF_SAADC, 0, NRF_SAADC_INPUT_AIN0, NRF_SAADC_INPUT_DISABLED);
	nrf_saadc_channel_init(NRF_SAADC, 0, &channel_config);

	// 配置 SAADC 分辨率：14位
	nrf_saadc_resolution_set(NRF_SAADC, NRF_SAADC_RESOLUTION_14BIT);

	// 配置采样模式：单次采样
	nrf_saadc_oversample_set(NRF_SAADC, NRF_SAADC_OVERSAMPLE_DISABLED);

	// 启用 SAADC
	nrf_saadc_enable(NRF_SAADC);

	// 等待 SAADC 稳定
	k_msleep(1);

	// 配置缓冲区（单次采样，只需要一个样本）
	int16_t sample_buffer[1] = {0};
	nrf_saadc_buffer_pointer_set(NRF_SAADC, sample_buffer);

	// 触发单次采样
	nrf_saadc_task_trigger(NRF_SAADC, NRF_SAADC_TASK_START);
	nrf_saadc_task_trigger(NRF_SAADC, NRF_SAADC_TASK_SAMPLE);

	// 等待采样完成（最多等待 100ms）
	int timeout = 100;
	while (!nrf_saadc_event_check(NRF_SAADC, NRF_SAADC_EVENT_END) && timeout > 0) {
		k_msleep(1);
		timeout--;
	}

	if (timeout == 0) {
		nrf_saadc_disable(NRF_SAADC);
		return -ETIMEDOUT;
	}

	// 清除事件标志
	nrf_saadc_event_clear(NRF_SAADC, NRF_SAADC_EVENT_END);

	// 读取采样值（14位，范围 0-16383）
	int16_t raw_value = sample_buffer[0];

	// 停止 SAADC
	nrf_saadc_task_trigger(NRF_SAADC, NRF_SAADC_TASK_STOP);
	nrf_saadc_disable(NRF_SAADC);

	// 检查采样值是否有效（应该为正数）
	if (raw_value <= 0) {
		printk("[电池电压] 错误: 采样值为 %d，请检查硬件连接\r\n", raw_value);
		*voltage_mv = 0;
		return -EIO;
	}

	// 计算 ADC 输入电压（毫伏）
	// 公式：ADC_Voltage = (raw_value / 16383) × 0.6V × 6 × 1000
	// 简化：ADC_Voltage = (raw_value × 6000) / 16383
	uint32_t adc_voltage_mv = ((uint32_t)raw_value * 6000ULL) / 16383ULL;

	// 计算实际电池电压（考虑分压比 0.5）
	// 实际电压 = ADC电压 × 分压比倒数 = ADC电压 × 2
	uint32_t battery_voltage_mv = adc_voltage_mv * VOLTAGE_DIVIDER_RATIO;

	// 限制在合理范围内（0-4200mV，对应 0-4.2V）
	if (battery_voltage_mv > 4200) {
		battery_voltage_mv = 4200;
	}

	*voltage_mv = (uint16_t)battery_voltage_mv;

	return 0;
}
```

**注意**：需要在文件开头添加必要的头文件：

```c
#include <hal/nrf_saadc.h>
```

**4. 计算公式**

```
// 分压电路计算
ADC_输入电压 = VBAT × (R2 / (R1 + R2))
            = VBAT × (480k / 960k)
            = VBAT × 0.5

// ADC 转换计算（14位，增益1/6，参考电压0.6V）
ADC_电压(mV) = (raw_value × 6000) / 16383

// 实际电池电压计算
实际电池电压 = ADC_电压 × 分压比倒数
            = ADC_电压 × 2
            = (raw_value × 12000) / 16383
```

**5. 在温湿度采集时调用**

```c
// 在 sample_work_handler() 函数中
uint16_t battery_voltage_mv = 0;
int battery_err = battery_voltage_read(&battery_voltage_mv);
if (battery_err == 0) {
    printk("[AHT30] 时间: %u, 温度: %d.%02d°C, 湿度: %d.%02d%%, 电压: %d.%03dV (%d mV)\r\n",
           current_time,
           temperature / 100, (temperature >= 0 ? temperature : -temperature) % 100,
           humidity / 100, humidity % 100,
           battery_voltage_mv / 1000, battery_voltage_mv % 1000, battery_voltage_mv);
}
```
