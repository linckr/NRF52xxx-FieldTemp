# nRF52832 + CH340 串口乱码排查

## 当前配置

- **52832 板级**（`boards/nrf52832dk_nrf52832_cpuapp.overlay`）：UART0 已设为 **4800** 波特率（因 115200/9600 在部分 CH340 上易乱码）。
- **终端**：必须与固件一致，设为 **4800 8N1**，无硬件流控。

## 若仍乱码请逐项检查

### 1. 波特率与格式一致

- 串口助手 / 终端：**4800，8 数据位，无校验，1 停止位（8N1）**。
- 关闭 RTS/CTS 等硬件流控。

### 2. CH340 使用注意

- **驱动**：安装 CH340 官方或最新驱动，设备管理器中 COM 口无叹号。
- **接线**：MCU TX（P0.18）→ CH340 **RX**；MCU RX（P0.14）→ CH340 **TX**；**GND 共地**。
- **电平**：nRF52832 为 3.3V，CH340 需 3.3V 兼容（或经电平转换）；5V 直连可能损坏或异常。

### 3. 可再试的波特率

若 4800 仍乱：

- 在 52832 overlay 中把 `current-speed` 改为 **2400** 再编译烧录，终端也改为 2400 8N1 测试。
- 若 2400 正常，多半是 MCU 侧时钟偏差导致高波特率不准；若 2400 仍乱，重点查接线、共地、CH340 驱动与电平。

### 4. 其他

- 换一根 USB 线或换一个 CH340 模块排除硬件故障。
- 若有 J-Link，可考虑用 **RTT** 看日志，不依赖 UART 波特率（需在 prj.conf 开启 `CONFIG_USE_SEGGER_RTT=y` 等）。
