# Flash 存储寿命分析

## 1. nRF52810 Flash 特性

### 1.1 Flash 规格

| 参数           | 数值             | 说明               |
| -------------- | ---------------- | ------------------ |
| **Flash 类型** | NOR Flash (内部) | 非易失性存储       |
| **总容量**     | 192 KB           | 包含代码和数据     |
| **页大小**     | 4 KB             | 最小擦除单位       |
| **扇区大小**   | 4 KB             | 与页大小相同       |
| **擦写次数**   | **10,000 次**    | 每个扇区的保证寿命 |
| **数据保持**   | 10 年            | 断电后数据保持时间 |

### 1.2 重要限制

- **页擦除**: Flash 只能按页（4KB）擦除，不能单独擦除字节
- **写入前必须擦除**: 写入前必须先擦除（擦除后全为 0xFF）
- **磨损均衡**: 需要实现磨损均衡算法，否则某些扇区会提前损坏

## 2. 不同存储方案的写入频率

### 2.1 方案对比

| 存储方案                        | 每次写入大小 | 擦除单位 | 写入频率 | 擦除频率 |
| ------------------------------- | ------------ | -------- | -------- | -------- |
| **NVS (Non-Volatile Storage)**  | 变量大小     | 4KB 页   | 每次更新 | 页满时   |
| **FCB (Flash Circular Buffer)** | 记录大小     | 4KB 页   | 每次记录 | 页满时   |
| **直接写入 Flash**              | 记录大小     | 4KB 页   | 每次记录 | 每次写入 |

### 2.2 温湿度数据存储场景

假设：

- 每条记录: **9 字节** (时间戳 4 + 温度 2 + 湿度 2 + 状态 1)
- 采集间隔: **30 秒**
- 每页可存: 4096 / 9 ≈ **455 条记录**

#### 方案 A: 每次采集都写入 Flash

```
写入频率: 每 30 秒 1 次
擦除频率: 每 455 次写入 = 每 3.8 小时擦除 1 页
每天擦除: 24 / 3.8 ≈ 6.3 页/天
寿命: 10,000 次 / 6.3 页/天 ≈ 1,587 天 ≈ 4.3 年
```

#### 方案 B: 批量写入（每 10 条记录写入一次）

```
写入频率: 每 5 分钟 1 次
擦除频率: 每 455 次写入 = 每 37.9 小时擦除 1 页
每天擦除: 24 / 37.9 ≈ 0.63 页/天
寿命: 10,000 次 / 0.63 页/天 ≈ 15,873 天 ≈ 43.5 年
```

#### 方案 C: 使用 NVS（带磨损均衡）

```
写入频率: 每次更新变量
擦除频率: 页满时（约 455 次更新）
磨损均衡: 自动分散到多个页
寿命: 10,000 次 × 页数 / 每天擦除次数
```

## 3. 详细寿命计算

### 3.1 最坏情况（无磨损均衡）

假设只使用 **1 页 Flash** (4KB) 存储数据：

| -------- | ---------- | ------------ | ------------ | ----------- |
| 3 秒     | 20 次/分钟 | 每 3.8 小时  | 6.3 次       | **4.3 年**  |
| 10 秒    | 6 次/分钟  | 每 12.6 小时 | 1.9 次       | **14.4 年** |
| 30 秒    | 2 次/分钟  | 每 37.9 小时 | 0.63 次      | **43.5 年** |
| 60 秒    | 1 次/分钟  | 每 75.8 小时 | 0.32 次      | **85.6 年** |

假设使用 **8 页 Flash** (32KB) 并实现磨损均衡：

| -------- | ---------- | ------------- | ------------ | ------------ |
| 3 秒     | 20 次/分钟 | 每 30.4 小时  | 0.79 次      | **34.6 年**  |
| 10 秒    | 6 次/分钟  | 每 100.8 小时 | 0.24 次      | **114.2 年** |
| 30 秒    | 2 次/分钟  | 每 303.2 小时 | 0.08 次      | **342.5 年** |
| 60 秒    | 1 次/分钟  | 每 606.4 小时 | 0.04 次      | **684.9 年** |

## 4. 实际推荐方案

### 4.1 方案对比表

| 方案                 | 优点               | 缺点     | 寿命       | 推荐度     |
| -------------------- | ------------------ | -------- | ---------- | ---------- |
| **RAM 缓存**         | 简单、快速、无损耗 | 断电丢失 | 无限       | ⭐⭐⭐⭐⭐ |
| **Flash + 磨损均衡** | 断电不丢失、寿命长 | 实现复杂 | 30-300+ 年 | ⭐⭐⭐⭐   |
| **Flash 无均衡**     | 实现简单           | 寿命短   | 4-85 年    | ⭐⭐⭐     |
| **混合方案**         | 兼顾两者           | 复杂     | 取决于策略 | ⭐⭐⭐⭐   |

### 4.2 推荐策略

#### 策略 1: 纯 RAM 缓存（推荐用于短期存储）

```
- 使用 RAM 环形缓冲区
- 采集间隔: 30-60 秒
- 可存: 200-300 条 (1.5-5 小时)
- 适用场景: 手机定期连接读取数据
```

#### 策略 2: RAM + Flash 备份（推荐用于长期存储）

```
- RAM 缓存: 200-300 条 (实时数据)
- Flash 备份: 每 10-30 条记录批量写入
- 采集间隔: 30-60 秒
- Flash 寿命: 43-85 年 (单页) 或 342-684 年 (8页均衡)
```

#### 策略 3: 纯 Flash（不推荐）

```
- 每次采集都写入 Flash
- 寿命: 4-43 年 (取决于采集间隔)
- 问题: 频繁擦写，寿命有限
```

## 5. 实现建议

### 5.1 如果使用 Flash 存储

#### 必须实现的功能：

1. **磨损均衡算法** - 分散写入到多个页
2. **批量写入** - 减少擦除频率
3. **错误检测** - CRC 校验数据完整性
4. **恢复机制** - 掉电恢复后重建索引

#### 推荐配置：

```c
// Flash 存储配置
#define FLASH_PAGE_SIZE       4096    // 4KB
#define FLASH_PAGES_COUNT     8       // 使用 8 页 (32KB)
#define RECORD_SIZE           9       // 每条记录 9 字节
#define RECORDS_PER_PAGE      455     // 每页 455 条
#define TOTAL_RECORDS         3640    // 总共 3640 条

// 写入策略
#define BATCH_WRITE_COUNT     10      // 每 10 条批量写入
#define SAMPLE_INTERVAL_SEC   30      // 30 秒采集一次

// 计算寿命
// 擦除频率: 每 455 次写入 = 每 37.9 小时
// 每天擦除: 0.63 次/天
// 8 页磨损均衡: 0.63 / 8 = 0.079 次/页/天
// 寿命: 10,000 / 0.079 = 126,582 天 ≈ 346 年
```

### 5.2 如果只使用 RAM 缓存

#### 优点：

- ✅ 实现简单
- ✅ 无 Flash 损耗
- ✅ 速度快
- ✅ 适合定期连接场景

#### 缺点：

- ❌ 断电丢失数据
- ❌ 容量有限（200-300 条）

## 6. 结论

### 对于您的应用场景：

**推荐方案: RAM 缓存 + 可选 Flash 备份**

1. **主要存储**: RAM 环形缓冲区（200-300 条）

   - 采集间隔: 30-60 秒
   - 可存: 1.5-5 小时数据
   - 无损耗，速度快

2. **可选备份**: Flash 批量写入（每 10-30 条）

   - 使用 8 页 + 磨损均衡
   - 寿命: 300+ 年
   - 断电不丢失

3. **使用场景**:
   - 手机定期连接（如每小时）→ 纯 RAM 足够
   - 需要长期离线存储 → 添加 Flash 备份
   - 需要断电保存 → 必须使用 Flash

### Flash 寿命总结

| 场景              | 写入频率   | 寿命（单页） | 寿命（8 页均衡） |
| ----------------- | ---------- | ------------ | ---------------- |
| 每次采集写入      | 每 30 秒   | **4.3 年**   | **34.6 年**      |
| 批量写入（10 条） | 每 5 分钟  | **43.5 年**  | **342.5 年**     |
| 批量写入（30 条） | 每 15 分钟 | **130 年**   | **1,000+ 年**    |

**建议**: 如果使用 Flash，**必须实现批量写入 + 磨损均衡**，否则寿命会很短。
