# 32.768kHz 晶振选型与功耗分析文档

## 1. 概述

本文档详细分析 nRF52810 使用 32.768kHz 3225 无源晶振替代内部 RC 振荡器的功耗影响、元器件选型、配置方法等内容。

---

## 2. 内部 RC vs 外部晶振功耗对比

### 2.1 内部 RC 振荡器（当前配置）

#### 功耗组成

**睡眠期间功耗：**

| 组件 | 功耗 | 说明 |
|------|------|------|
| System ON 睡眠 | 1-2 μA | MCU 深度睡眠 |
| RC 振荡器 | 0.5-1 μA | 基础振荡器功耗 |
| **RC 校准开销** | **6-8 μA** | 每4秒校准一次，平均约7μA<br>- 校准时会启动高频时钟（16MHz）<br>- 校准持续时间约200μs，功耗峰值可达数mA |
| **RC 频率不稳定额外开销** | **2-5 μA** | 平均约3.5μA<br>- RC频率漂移导致BLE接收窗口需要开得更长<br>- 等待时间增加，平均功耗上升 |
| **总睡眠功耗** | **10-13 μA** | **平均约 11.5 μA** |

**广播期间功耗：**

| 组件 | 功耗 | 说明 |
|------|------|------|
| 慢速广播功耗 | 0.2 mA | 正常广播功耗 |
| RC不稳定导致接收窗口增加 | 额外 2-5 μA | 平均约3.5μA |
| **总广播功耗** | **约 0.2035 mA** | - |

## 4. 10ppm vs 20ppm 的区别（功耗完全相同）

### 4.1 关键发现

**10ppm 和 20ppm 的功耗完全相同！**

- **10ppm 无源晶振**：驱动功耗约 **0.3-0.5 μA**
- **20ppm 无源晶振**：驱动功耗约 **0.3-0.5 μA**
- **功耗差异**：**0 μA**（完全相同）

**原因：** 无源晶振的功耗主要由驱动电路决定，与精度无关。

### 4.2 PPM（Parts Per Million）含义

PPM = Parts Per Million（百万分之一），表示频率精度。

| 参数 | 10 ppm | 20 ppm |
|------|--------|--------|
| **频率精度** | ±10 ppm | ±20 ppm |
| **32.768kHz 的最大偏差** | ±0.32768 Hz | ±0.65536 Hz |
| **相对误差** | ±0.001% | ±0.002% |
| **精度差异** | **2倍** | 基准 |

### 4.3 时间精度对比

#### 时间误差计算公式

```
时间误差 = (PPM值 / 1,000,000) × 时间
```

#### 不同运行时间下的误差对比

| 运行时间 | 10 ppm 误差 | 20 ppm 误差 | 差异 |
|---------|------------|------------|------|
| **1小时** | 0.036秒 | 0.072秒 | 0.036秒 |
| **1天** | **0.86秒** | **1.73秒** | 0.87秒 |
| **1周** | **6.05秒** | **12.1秒** | 6.05秒 |
| **1个月** | **25.9秒** | **51.8秒** | 25.9秒 |
| **3个月（90天）** | **77.8秒（1.3分钟）** | **155.5秒（2.6分钟）** | 77.7秒 |
| **6个月（180天）** | **155.5秒（2.6分钟）** | **311秒（5.2分钟）** | 155.5秒 |
| **1年（365天）** | **315秒（5.3分钟）** | **630秒（10.5分钟）** | 315秒 |

### 4.4 实际应用中的影响

#### 对20分钟采集间隔的影响

假设运行3个月：

| 精度 | 3个月累积误差 | 对时间戳的影响 |
|------|-------------|--------------|
| **10 ppm** | 约 77.8 秒（1.3 分钟） | 时间戳偏差约 ±1.3 分钟 |
| **20 ppm** | 约 155.5 秒（2.6 分钟） | 时间戳偏差约 ±2.6 分钟 |

**结论：** 对于20分钟采集间隔，两种精度的误差差异约1.3分钟，对时间戳记录影响不大。

### 4.5 成本对比（仅供参考）

| 精度 | 典型价格 | 价格差异 | 性价比 |
|------|---------|---------|--------|
| **10 ppm** | ¥0.5-1.0 | 高（约2倍） | 低 |
| **20 ppm** | ¥0.3-0.5 | 基准 | 高 |

### 4.6 选择建议

#### 选择 10ppm 的情况（成本不敏感时推荐）

**优势：**
- ✅ 时间精度更高（10ppm 精度是 20ppm 的 **2倍**）
- ✅ **功耗完全相同**（0.3-0.5 μA，与 20ppm 相同）
- ✅ 长期稳定性更好（温度变化时总误差更小）

**推荐场景：**
- 成本不敏感
- 需要更高精度的时间戳记录
- 需要长期运行（6个月以上）

#### 选择 20ppm 的情况

**优势：**
- ✅ 成本较低（约比 10ppm 便宜 40-50%）
- ✅ 功耗完全相同（与 10ppm 相同）
- ✅ 精度已足够（±2.6 分钟误差在 20 分钟采集间隔下可接受）

**推荐场景：**
- 成本敏感
- 对时间精度要求不高

**结论：** 如果成本不是问题，**推荐选择 10ppm**，因为功耗完全相同但精度更高。

## 6. 负载电容规格与计算

### 6.1 负载电容计算公式

```
CL = (C1 × C2) / (C1 + C2) + C_stray

其中：
- CL：晶振规格上的负载电容（如 12.5 pF）
- C1, C2：外部负载电容（通常相等）
- C_stray：寄生电容（PCB布线、焊盘等，通常 2-5 pF）
```

### 6.2 nRF52810 推荐配置

如果选择 **CL = 12.5 pF** 的晶振：

```
假设 C_stray = 2-3 pF（保守估算）

目标：CL = 12.5 pF

如果 C1 = C2 = C，则：
12.5 = (C × C) / (C + C) + 2.5
12.5 = C/2 + 2.5
C = 2 × (12.5 - 2.5) = 20 pF

因此：C1 = C2 = 18-22 pF（推荐 20-22 pF）
```

### 6.3 负载电容推荐规格

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| **封装** | 0402 或 0603 | SMD 封装 |
| **容值** | **22 pF ±5%** | 推荐值 |
| **温度特性** | **C0G/NP0** | 温度稳定性好 |
| **耐压** | ≥16V | - |
| **推荐型号** | GRM1885C1H220JA01（0603）<br>GRM1555C1H220JA01（0402） | 村田或同等规格 |

## 7. PCB 布局建议

### 7.1 晶振位置

- **尽量靠近** nRF52810 的 XL1/XL2 引脚
- **走线长度** < 10mm
- **走线对称**，等长

### 7.2 负载电容位置

- **尽量靠近晶振**
- C1 靠近晶振一端
- C2 靠近晶振另一端

### 7.3 布线规则

- **走线宽度**：0.15-0.2mm
- **走线间距**：尽量远离其他信号
- **地平面**：晶振下方保留地平面
- **避免走线**：晶振下方避免走其他信号线

## 10. 注意事项

### 10.1 晶振选择注意事项

1. **负载电容匹配**：必须选择 CL = 12.5 pF 的晶振
2. **ESR 范围**：ESR 应在 30-70 kΩ 范围内
3. **温度范围**：确保工作温度范围覆盖应用环境（-40°C ~ +85°C）

### 10.2 电容选择注意事项

1. **温度特性**：必须使用 C0G/NP0 材质（温度稳定性好）
2. **精度**：建议使用 ±5% 精度
3. **容值**：推荐 20-22 pF

### 10.3 调试验证

1. **晶振起振时间**：检查晶振起振时间（通常 0.3-1 秒）
2. **频率精度**：测试频率精度是否符合规格
3. **低功耗模式**：确认在低功耗模式下正常工作
4. **长期稳定性**：长期运行测试，确认时间精度稳定

## 11. 总结

### 11.1 关键结论

1. **功耗节省**：使用外部 32.768kHz 无源晶振可以节省约 **11 μA** 功耗（相比内部 RC）
2. **续航提升**：续航提升约 **9 天**（从 81 天到 90 天）
3. **10ppm vs 20ppm**：**功耗完全相同**，区别仅在于时间精度（10ppm 是 20ppm 的 2倍）
4. **推荐配置**：如果成本不敏感，推荐选择 **10ppm**（精度更高，功耗相同）

### 11.2 推荐配置

- **晶振**：32.768kHz, 3225, CL=12.5pF, ±10 ppm（如：FC-135 32.7680KA-A5）
- **负载电容**：22pF ±5%, C0G, 0402/0603（2 个，如：GRM1885C1H220JA01）
- **预期功耗节省**：约 **11 μA**（相比内部 RC）
- **预期续航提升**：约 **9 天**（从 81 天到 90 天）
