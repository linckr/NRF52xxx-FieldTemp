# SI2301 控制 AHT30 电源开关功耗评估

## 概述

本文档详细评估使用 SI2301（P 沟道 MOSFET）控制 AHT30 温湿度传感器电源开关的功耗节省效果，包括理论计算、实际场景分析和实施建议。

## 二、功耗分析

### 2.1 当前方案（无电源开关）

**AHT30 始终供电：**

| 状态 | 电流 | 时间占比 | 平均电流 |
|------|------|---------|---------|
| **测量状态** | 0.60 mA | 0.1 s / T | 0.60 mA × (0.1 / T) |
| **待机状态** | 0.015 mA | (T - 0.1) / T | 0.015 mA × ((T - 0.1) / T) |
| **总平均电流** | - | - | **0.60 × (0.1/T) + 0.015 × ((T-0.1)/T) mA** |

**简化计算（T >> 0.1 s）：**

\[
I_{avg,no\_switch} \approx 0.015 + \frac{0.06}{T} \text{ mA}
\]

其中 T 为采集间隔（秒）。

### 2.2 使用 SI2301 控制方案

**AHT30 仅在测量时供电：**

| 状态 | 电流 | 时间占比 | 说明 |
|------|------|---------|------|
| **测量状态** | 0.60 mA | 0.1 s / T | AHT30 工作电流 |
| **关断状态** | 0.001 mA | (T - 0.1) / T | SI2301 漏电流 |
| **总平均电流** | - | - | **0.60 × (0.1/T) + 0.001 × ((T-0.1)/T) mA** |

**简化计算（T >> 0.1 s）：**

\[
I_{avg,with\_switch} \approx 0.001 + \frac{0.06}{T} \text{ mA}
\]

**SI2301 导通损耗：**

- 导通电阻：RDS(on) = 0.12 Ω
- 测量电流：I = 0.60 mA
- 压降：V_drop = I × R = 0.60 mA × 0.12 Ω = 0.072 mV
- 功率损耗：P_loss = V_drop × I = 0.043 μW

**结论：** SI2301 导通损耗极小，可忽略不计。

## 三、功耗节省计算

### 3.1 不同采集间隔的功耗对比

#### 公式推导

**无开关方案平均电流：**
\[
I_{no} = 0.015 + \frac{0.06}{T} \text{ mA}
\]

**有开关方案平均电流：**
\[
I_{yes} = 0.001 + \frac{0.06}{T} \text{ mA}
\]

**节省电流：**
\[
\Delta I = I_{no} - I_{yes} = 0.015 - 0.001 = 0.014 \text{ mA} = 14 \text{ μA}
\]

**节省功率（3.3V 系统）：**
\[
\Delta P = \Delta I \times V = 14 \text{ μA} \times 3.3 \text{ V} = 46.2 \text{ μW}
\]

#### 不同采集间隔的详细对比

| 采集间隔 T | 无开关平均电流 | 有开关平均电流 | 节省电流 | 节省功率 | 节省比例 |
|-----------|--------------|--------------|---------|---------|---------|
| **1 秒** | 0.075 mA | 0.061 mA | **0.014 mA** | **46.2 μW** | **18.7%** |
| **10 秒** | 0.021 mA | 0.007 mA | **0.014 mA** | **46.2 μW** | **66.7%** |
| **60 秒** | 0.016 mA | 0.002 mA | **0.014 mA** | **46.2 μW** | **87.5%** |
| **300 秒（5分钟）** | 0.0152 mA | 0.0012 mA | **0.014 mA** | **46.2 μW** | **92.1%** |
| **600 秒（10分钟）** | 0.0151 mA | 0.0011 mA | **0.014 mA** | **46.2 μW** | **92.7%** |
| **3600 秒（1小时）** | 0.01502 mA | 0.00102 mA | **0.014 mA** | **46.2 μW** | **93.2%** |

**说明：**
- 节省电流为**固定值 14 μA**，与采集间隔无关
- 采集间隔越长，节省比例越高（因为待机时间占比增加）
- 在采集间隔 > 60 秒时，节省比例 > 85%

---

### 3.2 能量节省计算

#### 每日节省

**假设采集间隔为 60 秒：**

- 节省电流：14 μA
- 节省功率：46.2 μW
- 每日节省能量：46.2 μW × 24 h = **1.11 mWh/day**

#### 每月节省

- 每月（30 天）节省：1.11 mWh × 30 = **33.3 mWh/month**

#### 电池续航提升

**假设使用 CR2032 电池（220 mAh，3.0 V 平均电压 = 660 mWh）：**

- 当前系统总功耗：假设 5 mA（优化后）
- 当前续航：660 mWh / (5 mA × 3.0 V) = **44 小时**

**使用 SI2301 后：**
- 节省：14 μA
- 新功耗：5 mA - 0.014 mA ≈ 4.986 mA
- 新续航：660 mWh / (4.986 mA × 3.0 V) = **44.1 小时**

**续航提升：约 0.1 小时（6 分钟）**

**结论：** 对于总功耗较大的系统，SI2301 节省的功耗相对较小，续航提升有限。

## 七、技术实施方案

### 7.1 电路设计

#### 原理图

```
VDD (3.3V) ──┬── [SI2301 Source]
             │
             ├── [SI2301 Gate] ── [GPIO] (nRF52810)
             │                    (低电平开启，高电平关闭)
             │
             └── [SI2301 Drain] ── VDD_AHT30 ── AHT30 VDD
                                    │
                                   GND
```

#### 元件选型

| 元件 | 型号 | 说明 |
|------|------|------|
| **MOSFET** | SI2301 | P 沟道，SOT-23 |
| **上拉电阻** | 10 kΩ | Gate 上拉（可选） |
| **去耦电容** | 100 nF | AHT30 电源去耦 |

#### PCB 布局要点

1. **SI2301 位置**
   - 靠近 AHT30
   - 电源走线尽量短
   - 保留地平面

2. **去耦电容**
   - 靠近 AHT30 VDD 引脚
   - 使用 X7R 或 X5R 材质

3. **走线宽度**
   - 电源走线 ≥ 0.3 mm
   - 控制信号走线 ≥ 0.2 mm

### 7.2 软件实现

#### GPIO 控制

```c
// SI2301 控制引脚定义
#define AHT30_POWER_PIN  2  // 使用 P0.2（可根据实际设计调整）
#define AHT30_POWER_PORT NRF_P0

// 开启 AHT30 电源
static void aht30_power_on(void)
{
    // SI2301 是 P 沟道，低电平开启
    AHT30_POWER_PORT->OUTCLR = (1UL << AHT30_POWER_PIN);
    k_msleep(10);  // 等待电源稳定
}

// 关闭 AHT30 电源
static void aht30_power_off(void)
{
    // SI2301 是 P 沟道，高电平关闭
    AHT30_POWER_PORT->OUTSET = (1UL << AHT30_POWER_PIN);
}

// 初始化
static void aht30_power_init(void)
{
    // 配置 GPIO 为输出，初始状态为关闭
    AHT30_POWER_PORT->DIRSET = (1UL << AHT30_POWER_PIN);
    AHT30_POWER_PORT->OUTSET = (1UL << AHT30_POWER_PIN);  // 关闭
}
```

### 7.3 时序要求

#### 上电时序

```
GPIO 拉低 ──┐
            │
            ├── 10 ms ──> 电源稳定
            │
            ├── 100 ms ──> 传感器稳定
            │
            └──> 可以开始 I2C 通信
```

#### 下电时序

```
I2C 通信完成 ──┐
               │
               ├── 立即 ──> GPIO 拉高
               │
               └──> 电源关闭
```

**注意：**
- 上电后需要等待 100 ms 让传感器稳定
- 下电可以立即执行（无需等待）
- 确保 I2C 通信完成后再关闭电源

## 附录：计算公式汇总

### A. 无开关方案平均电流

\[
I_{no} = I_{idle} + \frac{I_{meas} \times t_{meas}}{T}
\]

其中：
- \(I_{idle} = 0.015 \text{ mA}\)（待机电流）
- \(I_{meas} = 0.60 \text{ mA}\)（测量电流）
- \(t_{meas} = 0.1 \text{ s}\)（测量时间）
- \(T\)（采集间隔，秒）

### B. 有开关方案平均电流

\[
I_{yes} = I_{leak} + \frac{I_{meas} \times t_{meas}}{T}
\]

其中：
- \(I_{leak} = 0.001 \text{ mA}\)（MOSFET 漏电流）
